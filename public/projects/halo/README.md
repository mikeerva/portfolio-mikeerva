# Halo — photographs

Every photograph in the Halo case study is a slot. Save a file here under its slot's name and
it replaces the placeholder; no code change is needed. Until then the page shows the brief.

All night scenes: a dark ground, one thing lit. Cyan (#2DD4C8) or magenta (#C0168F) appear only
as light — never as painted surfaces. No gold, no chips flying, no flashing.
