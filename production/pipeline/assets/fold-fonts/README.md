# FOLD specimen fonts

Used only to render the raster typography specimen; not installed into Windows.
Downloaded from the Google Fonts repository on 2026-10-11.

- Anton-Regular.ttf: https://github.com/google/fonts/tree/main/ofl/anton
- IBMPlexMono-Regular.ttf: https://github.com/google/fonts/tree/main/ofl/ibmplexmono
- Inter.ttf (variable): https://github.com/google/fonts/tree/main/ofl/inter
